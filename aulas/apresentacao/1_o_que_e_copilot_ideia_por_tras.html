O que é GitHub Copilot?

O que é GitHub Copilot

E a ideia por trás dele

Pair programming aumentado: humano + IA colaborando em tempo real

Definição e Propósito

  • Assistente de IA generativa integrado diretamente ao editor (VS Code, JetBrains, Neovim)
  • Sugere linhas, blocos, funções, testes e documentação em tempo real
  • Treinado em um amplo conjunto de código público e padrões consolidados
  • Objetivo: acelerar fluxo, reduzir tarefas repetitivas e desbloquear criatividade
  • Ideia central: pair programming aumentado - você decide, a IA auxilia

Evolução: Do Autocomplete ao Agent Mode

  • 2021: Lançamento - autocomplete inteligente de código
  • 2023: Copilot Chat - diálogo conversacional com contexto de projeto
  • 2024: Multi-modelo (GPT, Claude, Gemini) - escolha do modelo
  • 2025: Agent Mode - execução autônoma de tarefas multi-passo
  • 2025+: MCP, Custom Instructions, Copilot Extensions e coding agent

Pilares do GitHub Copilot

  • Contexto inteligente: entende arquivos abertos, imports, estrutura e estilo do projeto
  • Multi-modal: código, chat, terminal, edição inline, agente autônomo
  • Responsabilidade: filtragem de código inseguro, privacidade, aderência a licenças
  • Extensibilidade: MCP servers, custom instructions, extensions e skills
  • Evolução contínua: novos modelos e capacidades integrados regularmente
