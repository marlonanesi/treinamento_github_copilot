Conceitos universais de infraestrutura usando o Copilot

Copilot para Infraestrutura (DevOps/SRE)

Do desenho à execução segura e supervisionada

Visão geral (DevOps/SRE + Copilot)

  • Infra declarativa como código: previsível, rastreável e auditável.
  • Copilot usa o contexto do repo (pastas, manifests, workflows).
  • Gera rascunhos de infraestrutura rapidamente e com padrões.
  • Você supervisiona, revisa (PR) e aprova mudanças controladas.
  • Integra com CLIs e pipelines para fechar o ciclo (plan → apply → verify).

YAML é a base de muita infra

  • Kubernetes (Deployment, Service, Ingress, HPA, CronJob etc.).
  • Helm (Chart/values), Kustomize, ArgoCD, Docker Compose.
  • GitHub Actions (workflows), Renovate, Dependabot configs.
  • Vantagens: versionável, revisável, validável e automatizável.
  • Exemplo de prompt: “Gere Deployment + Service + Ingress p/ app X (porta Y, 3 réplicas, readiness Z).”

De requisitos de alto nível → YAMLs

  • Defina objetivos: imagem/porta, réplicas, recursos, env/secrets, domínios.
  • Peça ao Copilot: manifests K8s (Deployment/Service/Ingress/HPA).
  • Inclua CI: workflow de build/test/push e deploy (GitHub Actions).
  • Critérios: lints passando, validação de schema e rollout sucesso.
  • Itere: “adicione limits/requests”, “troque Ingress p/ NGINX”, “use namespace X”.

Plan → Apply → Verify (com confirmações)

  • Gere e valide: yamllint/actionlint, kubeconform/kubeval (dry-run).
  • Solicite confirmação antes de executar: kubectl apply/rollout, helm upgrade.
  • Verifique pós-apply: rollout status, logs, readiness/liveness, metrics.
  • Automatize via pipelines (PR → review → merge → deploy controlado).
  • Reaja a falhas: rollback/undo, corrija YAML e re-aplique.

Agente autônomo com guardrails

  • Fluxo orientado: o agente propõe → pede confirmação → executa.
  • Princípio do menor privilégio (RBAC) e ambientes (dev/stage/prod).
  • Políticas: OPA/Gatekeeper/Conftest; GitOps (ArgoCD) para convergência.
  • Segredos: External Secrets/Sealed Secrets; nunca em YAML plano.
  • Regra de ouro: nada em produção sem revisão humana e auditoria.
