Prompt, Comando e Contexto

Como se comunicar efetivamente com o GitHub Copilot

Assim como falamos diferente com cada pessoa, precisamos aprender a "falar" com a IA

A Arte da Comunicação

  • Com sua mãe: "Oi mãe, como você está?"
  • Com seu chefe: "Bom dia, Sr. Silva. Gostaria de discutir o projeto"
  • Com seu amigo: "E aí, cara! Bora pro happy hour?"
  • Com o Copilot: Também precisa do tom e contexto certo!

O que é um Prompt Efetivo?

  • Claro: "Criar função que valida email" vs "fazer validação"
  • Específico: "Para API REST, retornar true/false"
  • Contextual: "Usando regex padrão brasileiro"
  • Completo: "Com tratamento de erro e documentação"

Comandos e Boas Práticas

  • Use comandos diretos: /explain, /fix, /tests
  • Seja imperativo: "Refatore essa função" não "Você poderia..."
  • Dê exemplos: "Como esta função: getUserById(123)"
  • Especifique tecnologia: "Em TypeScript usando Express"

Estratégias Avançadas de Contexto

Maximizando a precisão das respostas

  • Contexto imediato: Selecione código relacionado antes do prompt
  • Histórico relevante: Referencie funções similares no projeto
  • Constraintes claros: "Sem usar bibliotecas externas"
  • Iteração: Refine o prompt baseado na resposta anterior
