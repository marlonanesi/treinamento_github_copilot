Engenharia de Prompt

Comunicação efetiva com o GitHub Copilot

A qualidade da saída depende diretamente da qualidade da entrada

A Analogia da Comunicação

  • Com sua mãe: "Oi mãe, como você está?" (casual, afetivo)
  • Com seu chefe: "Sr. Silva, gostaria de alinhar o escopo do projeto" (formal)
  • Com seu amigo: "E aí, cara! Bora pro happy hour?" (informal)
  • Com o Copilot: Claro, específico, contexto certo, tom imperativo
  • Insight: A IA responde melhor quando a instrução é precisa e direta

Anatomia de um Prompt Efetivo

  • Claro: "Criar função que valida email com regex" vs "fazer validação"
  • Específico: "Retornar boolean, cobrir domínios .com.br"
  • Contextual: "Para o módulo de cadastro do projeto Django"
  • Completo: "Com tratamento de erro, type hints e docstring"
  • Iterativo: Refine com base na resposta - cada iteração melhora o resultado

Metodologia PROMPT

Um framework para estruturar seus prompts

P · R · O · M · P · T - seis letras, um acrônimo prático

P - Persona & R - Role / Rules

  • P - Persona: Quem a IA deve "ser" - "Você é um dev sênior especialista em Python/FastAPI"
  • R - Role: Papel específico dentro da persona - ex: persona dev, role especialista em documentação
  • R - Rules: Regras e restrições - "Sempre use type hints, docstrings e SOLID"
  • R - Custom Instructions: .github/copilot-instructions.md para regras permanentes do projeto
  • Dica: Persona define quem é, Role define o foco, Rules define como agir

O · M · P · T

  • O - Objective: Objetivo claro - "Criar endpoint REST para CRUD de funcionários"
  • M - Methods: Como fazer - "Use repository pattern, exceções tratadas e logs estruturados"
  • P - Parameters: Stack e versões - "Python 3.12, Pydantic v2, pytest, FastAPI"
  • T - Tone ou Task: Tom da resposta ou tarefa específica - "Tom técnico. Retornar 401 se inválido, 403 se sem permissão"
  • Dica: Uma tarefa por prompt - prompts focados geram respostas melhores

PROMPT na Prática - Exemplo Completo

Aplicando o framework de ponta a ponta

  • P (Persona): "Você é um dev Python sênior especialista em APIs"
  • R (Role/Rules): "Role: especialista em segurança. Rules: clean architecture e SOLID"
  • O (Objective): "Criar middleware de autenticação JWT"
  • M (Methods): "Use decorator pattern, valide no startup, logue tentativas inválidas"
  • P (Parameters): "FastAPI, Python 3.12, PyJWT, Pydantic v2"
  • T (Tone/Task): "Tom técnico e direto. Retornar 401 se token inválido, 403 se sem permissão"

Estratégias Avançadas

Maximizando a precisão das respostas

  • Contexto explícito: Selecione código + use #file para referências
  • Few-shot: Dê 1-2 exemplos do padrão desejado antes de pedir
  • Constraints: "Sem bibliotecas externas, máximo 20 linhas"
  • Decomponha: Tarefas grandes = vários prompts menores e encadeados
  • Custom Instructions: Configure .github/copilot-instructions.md para o projeto
