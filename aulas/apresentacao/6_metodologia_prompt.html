Metodologia PROMPT

Estruturando comunicação efetiva com GitHub Copilot

Um framework sistemático para obter melhores resultados da IA

P - Persona & R - Role (Papel) *

  • Defina o papel: "Você é um desenvolvedor sênior especialista em Node.js"
  • Estabeleça expertise: "Como arquiteto de software experiente"
  • Contexto profissional: "Atuando em uma startup de fintech"
  • Exemplo: "Como especialista em React, crie um hook customizado..."
  • *Nota: R pode ser interpretado como Rules (Regras/Constraints)

R - Role vs Rules: Duas Interpretações

  • Role (Papel): "Como desenvolvedor React sênior"
  • Rules (Regras): "Sempre inclua tratamento de erro e comentários"
  • Na prática: Ambos são úteis e podem ser combinados
  • Exemplo híbrido: "Como expert em Node.js, seguindo padrões clean code"

O - Objective (Objetivo)

  • Seja específico: "Criar uma API REST para gerenciar usuários"
  • Defina escopo: "Com Cadastro Completo e validação de dados"
  • Especifique resultado: "Retornando JSON estruturado"
  • Exemplo: "Objetivo: Implementar autenticação JWT com refresh token"

M - Message & P - Parameters (Parâmetros)

  • Mensagem clara: "Implemente uma função de validação de email"
  • Parâmetros técnicos: "Usando TypeScript e regex"
  • Constraints: "Sem bibliotecas externas"
  • Exemplo: "Função validateEmail(email: string): boolean usando regex RFC 5322"

T - Task (Tarefa) - Exemplo Prático

Aplicando PROMPT completo no GitHub Copilot

  • P: "Como desenvolvedor Node.js sênior"
  • R: "Especialista em APIs RESTful"
  • O: "Criar middleware de autenticação"
  • M: "Implementar verificação de JWT"
  • P: "Express.js, TypeScript, error handling"
  • T: "Retornar 401 se token inválido, next() se válido"
