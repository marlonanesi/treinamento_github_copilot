Entendendo a Janela de Contexto

Context Window no GitHub Copilot

Como maximizar a eficiência das sugestões através do contexto adequado

O que é a Janela de Contexto?

  • Quantidade de informação (tokens) que o modelo consegue processar por requisição
  • Inclui: arquivo atual, arquivos abertos, imports, histórico do chat e instruções
  • Modelos atuais: 128k+ tokens (GPT, Claude) - muito maior que antes
  • Copilot otimiza automaticamente o que enviar para maximizar relevância
  • Impacto direto: mais contexto relevante = sugestões mais precisas

Como o Contexto Impacta as Sugestões

  • Funções complexas: Contexto insuficiente = sugestões genéricas e imprecisas
  • APIs específicas: Sem imports visíveis = métodos incorretos ou inventários
  • Padrões do projeto: Falta de exemplos = estilo inconsistente
  • Tipos customizados: Definições fora da janela = erros de tipagem
  • Regra de ouro: se você não vê a informação, o Copilot também não vê

Ferramentas de Gestão de Contexto

  • #file: Referencie arquivos específicos no chat para incluir no contexto
  • @workspace: Busca semântica em todo o projeto automaticamente
  • #selection: Inclua o código selecionado como referência no prompt
  • Custom Instructions: .github/copilot-instructions.md para regras do projeto
  • Arquivos abertos: Mantenha interfaces, types e constantes abertos

Boas Práticas de Contexto

Maximizando a eficiência do GitHub Copilot

  • Nomeação clara: Variáveis e funções autoexplicativas guiam o modelo
  • Estrutura modular: Arquivos pequenos e focados = contexto mais limpo
  • Documentação inline: JSDoc, docstrings, type hints enriquecem o contexto
  • Padrões consistentes: Convenções uniformes ajudam o modelo a prever intenção
  • Prompt iterativo: Refine com base na resposta anterior - o histórico é contexto
