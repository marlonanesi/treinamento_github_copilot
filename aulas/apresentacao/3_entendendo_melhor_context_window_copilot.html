Entendendo a Janela de Contexto

Context Window no GitHub Copilot

Como maximizar a eficiência das sugestões através do contexto adequado

O que é a Janela de Contexto?

  • Quantidade limitada de código que o Copilot consegue "ver"
  • Inclui: arquivo atual, arquivos abertos, imports e dependências
  • Aproximadamente 8.000 tokens (~6.000 palavras)
  • Impacto: Determina a qualidade das sugestões

Como o Contexto Impacta as Tarefas

  • Funções complexas: Contexto insuficiente = sugestões genéricas
  • APIs específicas: Sem imports visíveis = métodos incorretos
  • Padrões do projeto: Falta de exemplos = estilo inconsistente
  • Tipos customizados: Definições distantes = erros de tipagem

Estratégias para Melhor Uso do Contexto

  • Mantenha arquivos relacionados abertos: Interfaces, tipos, constantes
  • Coloque exemplos próximos: Funções similares no mesmo arquivo
  • Use comentários descritivos: Explique a intenção da função
  • Imports organizados: Mantenha dependências visíveis no topo
  • Engenharia de prompt: Como nos comunicamos "instruções" para o Copilot

Técnicas Avançadas de Contexto

Maximizando a eficiência do GitHub Copilot

  • Nomeação clara: Variáveis e funções autoexplicativas
  • Estrutura modular: Arquivos pequenos e focados
  • Documentação inline: JSDoc, docstrings para APIs
  • Padrões consistentes: Convenções de código uniformes
