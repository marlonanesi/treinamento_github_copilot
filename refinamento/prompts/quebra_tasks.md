# Janela de contexto no Copilot: historia.md e refinamento.md

Como especialista em arquitetura de software e Desenvolvedor Python SR, gere uma quebra lógica do refinamento do microserviço ms-cadastro-funcionario em até 10 Tasks, cada uma representando uma etapa para concluir a construção base (sem incluir implementação de testes, apenas preparando o código para ser testável futuramente).

## Para cada Task, inclua

- Nome da Task — curto e objetivo.
- Objetivo — o que será entregue nessa etapa.
- Principais entregas — bullet points com entregas concretas.
- Critério de pronto — o que indica que a Task está concluída.
- Prompt de execução — instrução clara para o Copilot gerar o código dessa etapa, com linguagem clara, detalhamento suficiente, contexto de tecnologias utilizadas, design esperado e passos estruturados.

## Orientações específicas para o Prompt de execução

Inclua orientações de boas práticas cobrindo:

- Organização de código e pastas.
- Uso correto das tecnologias (FastAPI, Pydantic, Motor, MongoDB, Docker etc.).
- Padrões de nomenclatura.
- Preocupações com desacoplamento e manutenibilidade.
- Preparação para testes futuros (injeção de dependências, separação de camadas).

## Entrega e organização dos arquivos

- Salve cada Task como um arquivo .md individual dentro da pasta refinamento/.
- Nomeie sequencialmente como: task_1.md, task_2.md, task_3.md, ….

## Ordem de implementação

- As Tasks devem seguir uma ordem lógica de implementação, da configuração inicial do projeto até a finalização da base.
- Use como referência a história e o refinamento técnico já abertos no editor.
